System & Architektur

SGS HEIRS ist eine hochsichere Plattform zur Verwaltung von digitalen Nachlässen und Zugangsberechtigungen. Das System verzichtet vollständig auf klassische Passwörter und setzt auf moderne asymmetrische Kryptografie.

  • Ed25519-Signatur: Passwortloser Login via QR-Code
  • DIN 5008 Briefe: Automatische Generierung via Apache PDFBox
  • AES-256-GCM: Verschlüsselte CSV- & Dokumentenablage
  • Audit-Trail: DSGVO-konforme, getrennte Logführung
